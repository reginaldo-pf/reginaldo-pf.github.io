3. Arquitetura do Projeto BiblioTauá: Pré-existente vs. TASK-204

Por que o repositório da Aula 24 possui mais arquivos do que o código digitado nos slides?

Simulação de Equipe Ágil
Base Pré-existente (Versão v0.3.0 das Sprints 01-03)

Em um time profissional, um novo ticket nunca começa com pasta vazia. O BiblioTauá já possui:

  • database.py: conexão e DDL SQLite
  • models/cliente.py: entidade discente
  • models/livro.py: acervo e estoque
  • models/item_pedido.py: item associativo
  • models/pedido.py: fechamento de compras
  • repositories/: persistência no banco
O Foco da Codificação de Hoje (Sprint 04 - TASK-204)

Nos slides e no live coding, focamos cirurgicamente no motor de cupons:

  • exceptions.py: erros de negócio da DUC UC04
  • models/cupom.py: entidade e validações
  • main.py: script para testar a implementação

Nas Aulas 25 e 26, o Cupom será persistido no SQLite e plugado ao Pedido!

Hierarquia de Erros: exceptions.py 

class BiblioTauaException(Exception):
    pass

class CupomInvalidoError(BiblioTauaException):
    pass

class CupomInexistenteError(CupomInvalidoError):
    def __init__(self, codigo: str):
        super().__init__(f"Cupom '{codigo}' nao encontrado.")

class CupomInativoError(CupomInvalidoError):
    def __init__(self, codigo: str):
        super().__init__(f"O cupom '{codigo}' esta inativo.")

class CupomExpiradoError(CupomInvalidoError):
    def __init__(self, codigo: str, validade: str):
        super().__init__(f"O cupom '{codigo}' expirou em {validade}.")

class CupomEsgotadoError(CupomInvalidoError):
    def __init__(self, codigo: str, limite: int):
        super().__init__(f"O cupom '{codigo}' atingiu o limite de {limite} usos.")

class ValorMinimoNaoAtingidoError(CupomInvalidoError):
    def __init__(self, codigo: str, valor_minimo: float, subtotal: float):
        super().__init__(
            f"O cupom '{codigo}' exige pedido minimo de R$ {valor_minimo:.2f}. "
            f"Subtotal atual: R$ {subtotal:.2f}."
        )

Entidade de Negócio: models/cupom.py 

@dataclass
class Cupom:
    codigo: str
    tipo_desconto: TipoDesconto
    valor_desconto: float
    valor_minimo_pedido: float = 0.0
    limite_usos: int = 100
    usos_realizados: int = 0
    validade_ate: date = date.today()
    ativo: bool = True
    id: Optional[int] = None

    def calcular_desconto(self, subtotal: float) -> float:
        # Valida compulsoriamente regras da DUC UC04
        self.pode_ser_aplicado_ao_pedido(subtotal)
        
        if self.tipo_desconto == TipoDesconto.PERCENTUAL:
            desconto = (subtotal * self.valor_desconto) / 100.0
        else:
            desconto = self.valor_desconto
        return round(min(desconto, subtotal), 2)
