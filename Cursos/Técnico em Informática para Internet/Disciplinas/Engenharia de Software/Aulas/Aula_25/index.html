3. Mão na Massa: Implementação da Persistência

Script DDL no SQLite e métodos seguros do CupomRepository.

Concluído no Encontro 2

Script DDL: database.py 

CREATE TABLE IF NOT EXISTS cupons (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    codigo TEXT NOT NULL UNIQUE,
    tipo_desconto TEXT NOT NULL CHECK(
        tipo_desconto IN ('PERCENTUAL', 'VALOR_FIXO')
    ),
    valor_desconto REAL NOT NULL CHECK(valor_desconto > 0),
    valor_minimo_pedido REAL NOT NULL DEFAULT 0.0,
    limite_usos INTEGER NOT NULL DEFAULT 100,
    usos_realizados INTEGER NOT NULL DEFAULT 0,
    validade_ate TEXT NOT NULL,
    ativo INTEGER NOT NULL DEFAULT 1
);

Incremento Atômico: CupomRepository 

def registrar_uso(self, cupom_id: int) -> bool:
    cursor = self.conn.cursor()
    cursor.execute("""
        UPDATE cupons
        SET usos_realizados = usos_realizados + 1
        WHERE id = ? AND usos_realizados < limite_usos AND ativo = 1
    """, (cupom_id,))
    self.conn.commit()
    if cursor.rowcount == 0:
        raise CupomEsgotadoError(0)
    return True
