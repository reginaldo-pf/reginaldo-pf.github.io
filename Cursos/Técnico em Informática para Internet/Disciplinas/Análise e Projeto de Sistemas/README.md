## 🎯 Ementa e Objetivos
Capacitar os estudantes na concepção, modelagem conceitual e desenho técnico de sistemas de informação complexos:
- Paradigma Orientado a Objetos aplicado à análise de sistemas.
- Linguagem de Modelagem Unificada (UML 2.5): Diagramas de Casos de Uso, Classes, Sequência, Atividades e Estados.
- Transição de Requisitos de Negócio para Modelos Técnicos.
- Padrões de Projeto de Software (GoF e GRASP).
- Documentação de Arquitetura de Software e Especificação Técnica.
