## 📚 Disciplinas Ofertadas

### 1. [Engenharia de Software](Disciplinas/Engenharia%20de%20Software)
- **Código:** TSII.210 / 17.202.9
- **Carga Horária:** 80h (Semestre 2)
- **Professor:** Reginaldo Pereira Fernandes
- **Foco:** Ciclo de vida de software, metodologias ágeis (Scrum/Kanban), especificação de requisitos, estimativas de esforço (Planning Poker, Monte Carlo) e arquitetura de aplicações.

### 2. [Análise e Projeto de Sistemas](Disciplinas/Análise%20e%20Projeto%20de%20Sistemas)
- **Código:** TSII.315 / 17.202.13
- **Carga Horária:** 40h (Semestre 3)
- **Professor:** Reginaldo Pereira Fernandes
- **Foco:** Modelagem orientada a objetos (UML), diagramas comportamentais e estruturais, padrões de análise e transição de requisitos para arquitetura de software.
