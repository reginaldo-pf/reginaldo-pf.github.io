Observação

Por que usar if __name__ == "__main__":?

O Python cria automaticamente variáveis internas chamadas de dunder (com dois sublinhados). Quando você executa o arquivo diretamente no terminal, o interpretador atribui o texto '__main__' à variável __name__. Esse padrão garante que o script só execute a função main() quando você o rodar diretamente, evitando execuções acidentais caso ele seja importado por outro módulo no futuro.

Passo 2: Mantendo o Software Vivo (while True)

Se você rodar o script agora (python main.py), ele exibe a mensagem e encerra imediatamente. Um sistema interativo precisa continuar rodando até que o usuário decida sair!

Atualize a sua função main() adicionando o laço de repetição:

def main():

    while True:
        pass  # comando temporário para não quebrar a sintaxe enquanto preparamos a tela
Dica Prática

O que é o pass?

Em Python, blocos de código (como while, if ou def) não podem ficar vazios. O comando pass é apenas uma instrução nula que serve de "marcador de posição" temporário.

Passo 2: Criar a Função Guardiã (obter_numero_positivo)

Se usarmos apenas float(input()) e o usuário digitar uma letra (como "abc"), o Python fecha o programa com um erro chamado ValueError. Além disso, o usuário poderia digitar um número negativo como -500.

Vamos criar uma função especialista que funciona como uma catraca de segurança: ela só deixa passar números válidos e positivos!

Acima da função main(), adicione a função abaixo:

def obter_numero_positivo(mensagem):
    """
    Solicita um número ao usuário e garante que seja
    um valor numérico válido (float) e não negativo.
    """
    while True:
        try:
            valor = float(input(mensagem))
            if valor >= 0:
                return valor
            print("Erro: O valor não pode ser negativo.")
        except ValueError:
            print("Erro: Digite um número válido (ex: 1500.50).")

🧠 Entendendo como essa função trabalha

  • try: (Tente): O Python tenta converter o texto digitado para número decimal (float).
  • if valor >= 0: return valor: Se deu certo e o número não é negativo, o comando return devolve o número imediatamente e encerra a função!
  • except ValueError:: Se o usuário digitou letras ou símbolos inválidos, em vez de o programa quebrar, ele pula para cá, exibe a mensagem de erro amigável e o while True repete a pergunta.

def exibir_relatorio(renda_prevista, despesas):
    """
    Calcula os totais por categoria, o saldo líquido e a conformidade com a regra 50-30-20.
    """
    print("\n--- Balanço e Análise Orçamentária ---")
    if renda_prevista == 0:
        print("Aviso: Defina a previsão de renda na opção 1 para um diagnóstico completo.")

    # 1. Acumuladores condicionais por categoria
    total_essencial = 0.0
    total_estilo_vida = 0.0
    total_reserva = 0.0

    for item in despesas:
        if item["categoria"] == "Essencial":
            total_essencial += item["valor"]
        elif item["categoria"] == "Estilo de Vida":
            total_estilo_vida += item["valor"]
        elif item["categoria"] == "Reserva":
            total_reserva += item["valor"]

    # 2. Cálculos gerais
    total_gasto = total_essencial + total_estilo_vida + total_reserva
    saldo_restante = renda_prevista - total_gasto

    # 3. Resumo financeiro formatado
    print(f"Renda Prevista : R$ {renda_prevista:>10.2f}")
    print(f"Total Despesas : R$ {total_gasto:>10.2f}")

    # 4. Diagnóstico de saúde financeira

def salvar_dados():
    """Salva a receita e a lista de despesas em um arquivo JSON."""
    pacote = {
        "renda_prevista": renda_prevista,
        "despesas": despesas
    }
    with open(ARQUIVO_DADOS, "w", encoding="utf-8") as arquivo:
        json.dump(pacote, arquivo, indent=4, ensure_ascii=False)


def carregar_dados():
    """Carrega os dados do arquivo JSON se ele já existir no computador."""
    global renda_prevista, despesas

    if os.path.exists(ARQUIVO_DADOS):
        try:
            with open(ARQUIVO_DADOS, "r", encoding="utf-8") as arquivo:
                pacote = json.load(arquivo)
                renda_prevista = pacote.get("renda_prevista", 0.0)
                despesas = pacote.get("despesas", [])
        except Exception:
            pass
