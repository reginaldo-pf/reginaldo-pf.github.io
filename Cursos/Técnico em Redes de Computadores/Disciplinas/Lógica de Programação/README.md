## 🎯 Ementa e Objetivos
Desenvolvimento do pensamento computacional e habilidades práticas de resolução de problemas algorítmicos através da linguagem de programação Python:
- Variáveis, tipos de dados primitivos e operadores aritméticos/lógicos.
- Estruturas de controle de fluxo condicional (`if`, `elif`, `else`).
- Estruturas de repetição (`while`, `for`).
- Manipulação avançada de sequências e strings.
- Estruturas de dados em Python: Listas, matrizes, tuplas e dicionários.
- Definição de funções, rotinas e escopo de variáveis.
- Desenvolvimento de projetos práticos e jogos em 2D utilizando `Pygame`.
