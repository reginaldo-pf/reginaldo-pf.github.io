## 🎯 Ementa e Objetivos
A disciplina capacita os discentes no ecossistema moderno de persistência poliglota, explorando as limitações do modelo relacional tradicional e as vantagens arquiteturais do paradigma NoSQL:
- Paradigma NoSQL e Trade-offs de Escalabilidade Horizontal.
- Teorema CAP (Brewer) e Teorema PACELC.
- Propriedades ACID vs BASE (*Basically Available, Soft state, Eventual consistency*).
- Modelo Chave-Valor (Redis): Estruturas em memória, caching e volatilidade.
- Modelo de Documentos (MongoDB): Schemas flexíveis, CRUD e Aggregation Framework.
- Modelo Orientado a Grafos (Neo4j) e Família de Colunas.
- Bancos de Dados Vetoriais (*Vector Databases*) e IA Generativa (RAG).
- Persistência Poliglota com containers Docker e APIs em Python (FastAPI).
