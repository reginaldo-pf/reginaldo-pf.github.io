Prática 1: MongoDB no Terminal (mongosh) e no Compass

Aprenda a operar o MongoDB de forma nativa sem nenhuma linha de Python. Pratique a criação de bancos, coleções, documentos com campos complexos (arrays e objetos aninhados) e filtros de busca.

1. Create Inserção de Documentos Ricos (insertOne / insertMany) 

// Seleciona a base de dados
use ecommerce_taua;

// Insere um notebook com especificacoes aninhadas e array de tags
db.produtos.insertOne({
  sku: "NOT-DEL-01",
  nome: "Notebook Dell Inspiron 15",
  categoria: "Informatica",
  preco: 4299.90,
  estoque: 14,
  especificacoes: {
    processador: "Intel Core i7 13ª Ger",
    memoria_gb: 16,
    ssd_gb: 512
  },
  tags: ["trabalho", "desenvolvimento", "bivolt"],
  ativo: true
});

2. Read Consultas Avançadas, Operadores de Comparação e Projeção 

// Consulta com projecao (apenas nome e preco, sem _id)
db.produtos.find(
  { categoria: "Informatica", preco: { $lt: 5000.00 } },
  { _id: 0, sku: 1, nome: 1, preco: 1 }
);

// Consulta em elementos de Array (busca se contem 'desenvolvimento')
db.produtos.find({ tags: "desenvolvimento" });

// Consulta em objeto aninhado (Dot Notation)
db.produtos.find({ "especificacoes.memoria_gb": { $gte: 16 } });

3. Update & Delete Operadores Atômicos ($set, $inc, $push) e Deleção 

// Atualizacao atomica: preco novo e adiciona nova tag na lista
db.produtos.updateOne(
  { sku: "NOT-DEL-01" },
  {
    $set: { preco: 3899.00 },
    $inc: { estoque: 5 },
    $push: { tags: "promocao_outubro" }
  }
);

// Remocao de produtos descontinuados
db.produtos.deleteMany({ ativo: false });

Prática 2: Redis no Terminal (redis-cli) e no Redis Insight

O Redis é um banco de dados em memória ultrarrápido com 5 estruturas centrais de dados. Pratique cada estrutura no terminal CLI e inspecione o uso de memória no Redis Insight.

1. Strings, TTL e Contadores

# Token de sessao com TTL de 90 segundos
SET session:user_42 "jwt_token_taua_2026" EX 90
GET session:user_42
TTL session:user_42

# Contador atomico de visualizacoes
SET views:NOT-DEL-01 100
INCR views:NOT-DEL-01
INCRBY views:NOT-DEL-01 15

2. Hashes: Carrinho de Compras

# Adiciona itens ao carrinho (SKU -> Qtd)
HSET cart:session_77 "NOT-DEL-01" 1 "MOU-LOG-02" 2

# Incrementa quantidade de um item
HINCRBY cart:session_77 "MOU-LOG-02" 1

# Recupera todos os itens e quantidades
HGETALL cart:session_77

3. Lists: Fila FIFO de Pedidos

# Produtor insere na cauda (RPUSH)
RPUSH fila:pedidos "PED-1001" "PED-1002"

# Consumidor retira da cabeca (LPOP)
LPOP fila:pedidos

# Consulta fila sem remover
LRANGE fila:pedidos 0 -1

4. Sorted Sets: Leaderboards

# Ranking de produtos mais vendidos
ZADD ranking 45 "MOU-LOG-02" 12 "NOT-DEL-01" 70 "CAB-USBC-05"

# Top 3 produtos mais vendidos decrescente
ZREVRANGE ranking 0 2 WITHSCORES

Prática 3: Integração com Python (pymongo + redis-py)

Veja como conectar os dois bancos em uma aplicação real utilizando o padrão Cache-Aside (Lazy Loading). A aplicação consulta o Redis primeiro e, em caso de falta (Cache Miss), busca no MongoDB e alimenta o cache com TTL.

Implementação do Serviço com Cache e Invalidação

import json, time

class CacheAsideService:
    def __init__(self, mongo_col, redis_cli, ttl_segundos=120):
        self.mongo_col = mongo_col
        self.redis = redis_cli
        self.ttl = ttl_segundos

    def obter_produto(self, sku: str):
        cache_key = f"cache:produto:{sku}"
        
        # 1. Tenta recuperar da memoria RAM (Redis)
        dado_cache = self.redis.get(cache_key)
        if dado_cache:
            # CACHE HIT: Latencia sub-milissegundo (< 0.5 ms)
            return json.loads(dado_cache), "CACHE_HIT"
            
        # 2. CACHE MISS: Busca no banco de documentos em disco (MongoDB)
        produto_db = self.mongo_col.find_one({"sku": sku}, {"_id": 0})
        if not produto_db:
            return None, "NOT_FOUND"
            
        # 3. Popula o cache no Redis com TTL de expiracao
        self.redis.set(cache_key, json.dumps(produto_db), ex=self.ttl)
        return produto_db, "CACHE_MISS"

    def atualizar_preco(self, sku: str, novo_preco: float):
        # Atualiza a fonte da verdade (MongoDB)
        self.mongo_col.update_one({"sku": sku}, {"$set": {"preco": novo_preco}})
        
        # Invalida o cache no Redis imediatamente para evitar dado obsoleto
        cache_key = f"cache:produto:{sku}"
        self.redis.delete(cache_key)
        print(f"Preco gravado e cache invalidado para {sku}")
