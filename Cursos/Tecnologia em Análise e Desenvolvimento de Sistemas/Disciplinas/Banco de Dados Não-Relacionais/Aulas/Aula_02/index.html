Como Configurar Write Concern e Read Concern no MongoDB

Níveis de Escrita (Write Concern)

// 1. Baixa Latência (PA/EL)
db.sensores.insertOne(
  { sensor: "TAU-01", temp: 31.2 },
  { writeConcern: { w: 1, wtimeout: 1000 } }
);

// 2. Alta Consistência e Durabilidade Bancária (PC/EC)
db.transferencias.insertOne(
  { de: "CTA-100", para: "CTA-200", valor: 1500.00 },
  { writeConcern: { w: "majority", j: true, wtimeout: 5000 } }
);

Níveis de Leitura (Read Concern)

// 1. Leitura Local (Rápida, mas risco de Stale Read)
db.pedidos.find({ status: "pendente" })
  .readConcern("local");

// 2. Leitura de Quórum (Apenas dados confirmados pela maioria)
db.pedidos.find({ id_pedido: "PED-2026-09" })
  .readConcern("majority");

// 3. Leitura Linearizável (Ordem estrita com líder)
db.contas.find({ id_cliente: 42 })
  .readConcern("linearizable");

Plano de Ensino & Exercícios de Fixação (Lista 1 - Bloco 2)

Objetivos Gerais e Específicos

Capacitar o estudante a entender as restrições físicas de redes distribuídas, dominar a formulação de Brewer e Abadi, discernir quando uma aplicação corporativa exige garantias ACID ou tolera consistência eventual BASE, e aplicar esses princípios no MongoDB.

Exercícios de Fixação para Entrega:

  1. Por que a afirmação popular "Basta escolher 2 dentre C, A e P no Teorema CAP" é considerada conceitualmente incorreta na engenharia moderna segundo Eric Brewer (2012)?
  2. Explique detalhadamente por que um cluster distribuído com $N = 4$ nós votantes é mais vulnerável a paradas operacionais (downtime) do que um cluster com $N = 3$ nós sob a ocorrência de uma partição de rede binária estrita.
  3. Defina a equação mnemônica do Teorema PACELC de Daniel Abadi (2012). Qual é a limitação central do Teorema CAP que o PACELC visa solucionar?
  4. Contrastando os paradigmas ACID e BASE, diferencie o conceito de Isolamento Pessimista baseado em Travas do conceito de Consistência Eventual Otimista.
  5. Considere o algoritmo Last-Write-Wins (LWW) utilizado para resolução de conflitos em sistemas AP. Qual é a fragilidade física desse método quando há desvio de relógio (Clock Drift) entre os servidores de um cluster?
  6. No MongoDB, qual é a diferença operacional entre executar uma gravação com { writeConcern: { w: 1 } } e executar a mesma gravação com { writeConcern: { w: "majority", j: true } }? Em qual quadrante do Teorema PACELC cada uma se posiciona?
