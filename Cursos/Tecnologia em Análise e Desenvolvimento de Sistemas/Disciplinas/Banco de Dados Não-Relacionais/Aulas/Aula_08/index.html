Cláusula SQL Tradicional Estágio do MongoDB Comportamento e Impacto no Banco
WHERE condicao $match Filtra tuplas antes de agregar; aproveita índices B-Tree quando no topo do pipeline.
SELECT a, b + c AS x $project / $addFields Modifica as colunas exibidas, descarta chaves ou adiciona campos calculados.
GROUP BY chave $group: { _id: "$campo" } Sintetiza documentos com base na chave única ou composta informada no _id.
HAVING SUM(x) > 100 $match (pós-$group) Filtra o resultado consolidado do agrupamento.
ORDER BY x DESC $sort: { x: -1 } Ordena os documentos. Requer cuidado com o limite de 100 MB se não for indexado.
LEFT JOIN tabela $lookup Realiza junção entre coleções, anexando os dados relacionados como um array.
UNNEST / EXPLODE(arr) $unwind: "$array" Desmembra cada elemento do array em um documento independente no fluxo.

1. Faturamento Mensal e Ticket Médio (MongoSH)

Combinação encadeada de $match, $group com ano/mês, projeção formatada e ordenação cronológica.

db.pedidos.aggregate([
  { $match: { status: "ENTREGUE" } },
  {
    $group: {
      _id: {
        ano: { $year: "$data_criacao" },
        mes: { $month: "$data_criacao" }
      },
      faturamento_total: { $sum: "$pagamento.total_pago" },
      ticket_medio: { $avg: "$pagamento.total_pago" },
      quantidade_pedidos: { $sum: 1 }
    }
  },
  {
    $project: {
      _id: 0,
      periodo: {
        $concat: [
          { $toString: "$_id.ano" }, "-",
          { $cond: [{ $lt: ["$_id.mes", 10] }, { $concat: ["0", { $toString: "$_id.mes" }] }, { $toString: "$_id.mes" }] }
        ]
      },
      faturamento: { $round: ["$faturamento_total", 2] },
      ticket_medio: { $round: ["$ticket_medio", 2] },
      pedidos: "$quantidade_pedidos"
    }
  },
  { $sort: { periodo: 1 } }
]);

2. Desconstrução de Arrays com $unwind, $lookup e Top Produtos (Python)

Uso do driver oficial PyMongo para desmembrar a lista de itens de pedidos, enriquecer com dados do catálogo via $lookup e ranquear os produtos mais rentáveis.

from pymongo import MongoClient

client = MongoClient("mongodb://localhost:27017")
db = client["ecommerce_shopgrids"]

pipeline = [
    {"$match": {"status": "ENTREGUE"}},
    {"$unwind": "$itens"},
    {
        "$lookup": {
            "from": "produtos",
            "localField": "itens.sku",
            "foreignField": "sku",
            "as": "detalhes"
        }
    },
    {"$unwind": "$detalhes"},
    {
        "$group": {
            "_id": "$itens.sku",
            "produto": {"$first": "$detalhes.titulo"},
            "categoria": {"$first": "$detalhes.categoria"},
            "unidades_vendidas": {"$sum": "$itens.qtd"},
            "receita_total": {"$sum": {"$multiply": ["$itens.preco", "$itens.qtd"]}}
        }
    },
    {"$sort": {"receita_total": -1}},
    {"$limit": 5}
]

for prod in db.pedidos.aggregate(pipeline):
    print(f"[{prod['_id']}] {prod['produto']:<30} | Qtd: {prod['unidades_vendidas']:>4} | Total: R$ {prod['receita_total']:>10.2f}")

3. Enriquecimento Cadastral com $lookup em Clientes (MongoSH)

Cruzamento entre pedidos e a coleção clientes via chave indexada cliente_id para exibir nome e cidade/estado do comprador.

db.pedidos.aggregate([
  { $match: { status: "ENTREGUE" } },
  { $sort: { "pagamento.total_pago": -1 } },
  { $limit: 5 },
  {
    $lookup: {
      from: "clientes",
      localField: "cliente_id",
      foreignField: "cliente_id",
      as: "cliente"
    }
  },
  { $unwind: "$cliente" },
  {
    $project: {
      _id: 0,
      codigo: 1,
      cliente: "$cliente.nome",
      local: { $concat: ["$cliente.cidade", "/", "$cliente.estado"] },
      segmento: "$cliente.segmento",
      total_pago: "$pagamento.total_pago"
    }
  }
]);

4. Catálogo com Média de Avaliações ($lookup em Avaliações - Python)

Cálculo dinâmico da satisfação do consumidor calculando a média das notas e o volume total de reviews embutidos.

pipeline_avaliacoes = [
    {"$match": {"categoria": "Informática", "status": "ATIVO"}},
    {
        "$lookup": {
            "from": "avaliacoes",
            "localField": "sku",
            "foreignField": "sku",
            "as": "reviews"
        }
    },
    {
        "$project": {
            "_id": 0,
            "sku": 1,
            "titulo": 1,
            "preco": 1,
            "total_avaliacoes": {"$size": "$reviews"},
            "nota_media": {"$round": [{"$avg": "$reviews.nota"}, 1]}
        }
    },
    {"$match": {"total_avaliacoes": {"$gte": 2}}},
    {"$sort": {"nota_media": -1, "total_avaliacoes": -1}},
    {"$limit": 5}
]

for prod in db.produtos.aggregate(pipeline_avaliacoes):
    print(f"[{prod['sku']}] {prod['titulo'][:30]:<30} | R$ {prod['preco']:>8.2f} | Reviews: {prod['total_avaliacoes']:>2} | Média: {prod['nota_media']} ★")

Desafios de Laboratório para os Estudantes

Desafio 1: Distribuição de Faturamento por Status

Escreva um pipeline que agrupe pelo campo status ('ENTREGUE', 'CANCELADO', 'PENDENTE', etc.) e calcule faturamento total somando pagamento.total_pago, ticket médio e volume de transações.

Desafio 2: Ranking de Clientes VIP com Enriquecimento Cadastral

Filtre pedidos entregues (status: 'ENTREGUE'), agrupe por cliente_id e some o total gasto. Em seguida, utilize $lookup com a coleção clientes para recuperar o nome do cliente, cidade, estado e segmento dos 5 maiores compradores da loja.

Desafio 3: Satisfação de Clientes no Catálogo ($lookup em Avaliações)

A partir da coleção produtos (categoria 'Informática' e status 'ATIVO'), execute um $lookup com a coleção avaliacoes pela chave sku. Projete a nota média, o total de avaliações recebidas e filtre apenas itens com nota $\ge 4.5$ e no mínimo 2 reviews.

Desafio 4: Faturamento Geográfico por Estado (UF)

Construa um pipeline sobre a coleção pedidos que faça junção com clientes e agrupe pelo campo cliente.estado, gerando o ranking dos estados líderes em receita entregue e ticket médio.
