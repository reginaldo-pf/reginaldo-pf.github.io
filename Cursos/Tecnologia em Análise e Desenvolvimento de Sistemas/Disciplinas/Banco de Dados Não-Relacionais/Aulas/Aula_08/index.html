Cláusula SQL Tradicional Estágio do MongoDB Comportamento e Impacto no Banco
WHERE condicao $match Filtra tuplas antes de agregar; aproveita índices B-Tree quando no topo do pipeline.

GROUP BY chave $group: { _id: "$campo" } Sintetiza documentos com base na chave única ou composta informada no _id.
HAVING SUM(x) > 100 $match (pós-$group) Filtra o resultado consolidado do agrupamento.
ORDER BY x DESC $sort: { x: -1 } Ordena os documentos. Requer cuidado com o limite de 100 MB se não for indexado.
LEFT JOIN tabela $lookup Realiza junção entre coleções, anexando os dados relacionados como um array.
UNNEST / EXPLODE(arr) $unwind: "$array" Desmembra cada elemento do array em um documento independente no fluxo.

1. Faturamento Mensal e Ticket Médio (MongoSH)

Combinação encadeada de $match, $group com ano/mês, projeção formatada e ordenação cronológica.

db.pedidos.aggregate([
  { $match: { status: "entregue" } },
  {
    $group: {
      _id: {
        ano: { $year: "$data_pedido" },
        mes: { $month: "$data_pedido" }
      },
      faturamento_total: { $sum: "$valor_total" },
      lucro_total: { $sum: "$lucro_bruto" },
      ticket_medio: { $avg: "$valor_total" },
      quantidade_pedidos: { $sum: 1 }
    }
  },
  {
    $project: {
      _id: 0,
      periodo: {
        $concat: [
          { $toString: "$_id.ano" }, "-",
          { $cond: [{ $lt: ["$_id.mes", 10] }, { $concat: ["0", { $toString: "$_id.mes" }] }, { $toString: "$_id.mes" }] }
        ]
      },
      faturamento: { $round: ["$faturamento_total", 2] },
      ticket_medio: { $round: ["$ticket_medio", 2] },
      pedidos: "$quantidade_pedidos"
    }
  },
  { $sort: { periodo: 1 } }
]);

2. Desconstrução de Arrays com $unwind e Top Produtos (Python)

Uso do driver oficial PyMongo para desmembrar a lista de itens de pedidos e ranquear os produtos mais rentáveis.

from pymongo import MongoClient

client = MongoClient("mongodb://localhost:27017")
db = client["ecommerce_shopgrids"]

pipeline = [
    {"$match": {"status": "entregue"}},
    {"$unwind": "$itens"},
    {
        "$group": {
            "_id": "$itens.sku",
            "produto": {"$first": "$itens.nome"},
            "categoria": {"$first": "$itens.categoria"},
            "unidades_vendidas": {"$sum": "$itens.quantidade"},
            "receita_total": {"$sum": "$itens.subtotal"}
        }
    },
    {"$sort": {"receita_total": -1}},
    {"$limit": 5}
]

for prod in db.pedidos.aggregate(pipeline):
    print(f"[{prod['_id']}] {prod['produto']:<30} | Qtd: {prod['unidades_vendidas']:>4} | Total: R$ {prod['receita_total']:>10.2f}")
