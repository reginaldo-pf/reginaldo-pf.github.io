# Modelo de Disciplina - Tecnologia em Telemática

Esta pasta serve como modelo base para novas disciplinas do curso de Tecnologia em Telemática.

## Estrutura Recomendada:
- `Aulas/`: Aulas organizadas em `Aula_01/`, `Aula_02/`, etc., contendo `codigo/`, `materiais/` e `README.md`.
- `Avaliacoes/`: Provas teóricas (AVT), provas práticas (AVP) e listas de exercícios.
- `Referencias/`: Ementas, livros, artigos e apostilas.
