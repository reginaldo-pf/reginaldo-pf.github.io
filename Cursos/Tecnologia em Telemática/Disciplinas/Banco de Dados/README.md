## 🎯 Ementa e Objetivos
A disciplina capacita os discentes nos conceitos fundamentais de modelagem, projeto e implementação de Sistemas Gerenciadores de Banco de Dados Relacionais (SGBD-R):
- Introdução aos Sistemas de Banco de Dados e arquitetura ANSI/SPARC.
- Modelagem Conceitual: Modelo Entidade-Relacionamento (MER) e Diagramas Entidade-Relacionamento Estendidos.
- Modelo Lógico Relacional e mapeamento MER para o modelo relacional.
- Álgebra Relacional e Teoria da Normalização (1FN, 2FN, 3FN e BCNF).
- Linguagem SQL padrão: DDL (definição de dados), DML (manipulação de dados), DCL (controle) e DQL (consultas complexas com `JOIN`, subconsultas e funções agregadas).
- Visões (Views), Índices e noções de processamento de transações (propriedades ACID).
