## 🎯 Ementa e Objetivos
A disciplina capacita o discente nos conceitos fundamentais de modelagem conceitual, projeto lógico relacional, normalização e implementação em Sistemas Gerenciadores de Banco de Dados Relacionais (SGBD-R):
- **Conceitos e Arquitetura de BD:** Arquitetura ANSI/SPARC de 3 níveis, independência de dados e catálogo do sistema.
- **Modelagem Conceitual:** Modelo Entidade-Relacionamento (MER), diagramas DER, entidades fortes e fracas, atributos e cardinalidades.
- **Modelo Relacional e Álgebra:** Mapeamento MER $\to$ Relacional, restrições de integridade, operadores fundamentais da Álgebra Relacional e Cálculo Relacional.
- **Teoria do Projeto Relacional:** Dependências funcionais e Normalização (1FN, 2FN, 3FN e BCNF).
- **Linguagem SQL Padrão:** SQL DDL (`CREATE`, `ALTER`, `DROP`, constraints), SQL DML (`INSERT`, `UPDATE`, `DELETE`) e SQL DQL avançada (`JOINs`, subconsultas, `GROUP BY`, `HAVING`).
- **Tópicos Avançados de SGBD:** Visões (`VIEWs`), Índices, Transações ACID, Programação em PL/pgSQL (Funções e Triggers) e integração com aplicações Python.

## 📊 Sistema de Avaliação (Baseado em Listas e Projetos)

A avaliação da disciplina é estruturada em dois períodos (N1 e N2), combinando rigor teórico, resolução sistemática de exercícios e desenvolvimento de um **Projeto de Banco de Dados Real para Telemática**:

* **Período N1:**
  $$N1 = (AVT1 \times 0.40) + (AVP1_{\text{Projeto Fase 1}} \times 0.40) + (\overline{\text{Listas}}_{1,2,3} \times 0.20)$$
  - **AVT1:** Avaliação Teórica escrita individual (Aula 21).
  - **AVP1 (Projeto Fase 1):** Concepção, DER conceitual, mapeamento relacional e normalização em 3FN com script DDL inicial.
  - **Listas N1:** Três listas aplicadas preferencialmente nos sábados letivos assíncronos (Listas 01, 02 e 03).

* **Período N2:**
  $$N2 = (AVT2 \times 0.40) + (AVP2_{\text{Projeto Fase 2}} \times 0.40) + (\overline{\text{Listas}}_{4,5,6} \times 0.20)$$
  - **AVT2:** Avaliação Teórica escrita individual (Aula 39).
  - **AVP2 (Projeto Fase 2):** Implementação completa no PostgreSQL, carga DML, consultas analíticas com JOINs, Views, Triggers/Functions e script Python integrado (Aula 40).
  - **Listas N2:** Três listas aplicadas no período (Listas 04, 05 e 06).
