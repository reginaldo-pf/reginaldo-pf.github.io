1. A Arquitetura ANSI/SPARC e os Níveis de Abstração

Proposta em 1975 pelo comitê ANSI/X3/SPARC, a arquitetura de três níveis estabeleceu os alicerces dos Sistemas Gerenciadores de Bancos de Dados modernos. Seu propósito fundamental é desacoplar a forma como os usuários e aplicações interagem com os dados da maneira como os bytes estão organizados fisicamente em disco:

Nível Externo

Visões personalizadas (Views) e interfaces específicas de cada usuário ou microsserviço. Oculta dados irrelevantes e assegura privacidade.

Nível Conceitual

Modelo lógico global da organização. Descreve todas as entidades, atributos, relacionamentos e restrições de integridade corporativas.

Nível Interno

Estruturas físicas de armazenamento: blocos de disco, páginas de 8KB, ordenação de registros e caminhos de acesso indexados (Árvores B+).

A transição entre esses níveis é mediada por mapeamentos. Isso viabiliza a Independência Lógica de Dados (alterar tabelas conceituais sem quebrar visões de usuários) e a Independência Física de Dados (criar índices ou reestruturar arquivos sem alterar a lógica das consultas).

In [1]: DDL: Definição de Esquema Conceitual de Ativos de Rede 
import sqlite3

# Conexão com SGBD relacional em memória
conn = sqlite3.connect(":memory:")
cursor = conn.cursor()

# DDL: Criação das tabelas com integridade referencial e validação CHECK
cursor.execute("""
CREATE TABLE roteadores_core (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hostname TEXT NOT NULL UNIQUE,
    ip_gerencia TEXT NOT NULL UNIQUE,
    fabricante TEXT NOT NULL,
    modelo TEXT NOT NULL,
    capacidade_gbps INTEGER NOT NULL CHECK (capacidade_gbps > 0)
);
""")

cursor.execute("""
CREATE TABLE circuitos_fibra (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    codigo_circuito TEXT NOT NULL UNIQUE,
    roteador_origem_id INTEGER NOT NULL,
    interface_local TEXT NOT NULL,
    banda_mbps INTEGER NOT NULL,
    status_operacional TEXT NOT NULL DEFAULT 'DOWN',
    FOREIGN KEY (roteador_origem_id) REFERENCES roteadores_core(id)
);
""")

print("✅ [DDL] Tabelas 'roteadores_core' e 'circuitos_fibra' criadas com sucesso.")

In [2]: Catálogo do Sistema: Consulta a Metadados em sqlite_master 
# Introspecção do Dicionário de Dados interno do SGBD
query_catalogo = """
SELECT type, name, tbl_name, sql 
FROM sqlite_master 
WHERE type IN ('table', 'index') AND name NOT LIKE 'sqlite_%';
"""

cursor.execute(query_catalogo)
for obj_type, name, tbl_name, sql_def in cursor.fetchall():
    print(f"-> Tipo: {obj_type.upper():<5} | Objeto: {name:<16} | Tabela: {tbl_name}")
    print(f"   DDL no Catálogo:\n   {sql_def.strip()}\n")

In [3]: DML, DQL e Demonstração de Independência de Dados 
# DML: Carga de roteadores
cursor.executemany("""
INSERT INTO roteadores_core (hostname, ip_gerencia, fabricante, modelo, capacidade_gbps)
VALUES (?, ?, ?, ?, ?);
""", [
    ("TAU-CORE-01", "10.200.1.1", "Cisco", "ASR-9006", 400),
    ("TAU-EDGE-01", "10.200.1.2", "Juniper", "MX480", 240)
])

# Independência Lógica: adicionando coluna de gerência sem quebrar programas existentes
cursor.execute("ALTER TABLE roteadores_core ADD COLUMN snmp_community TEXT DEFAULT 'public';")

# Independência Física: criando índice B-tree para aceleração de busca no nível interno
cursor.execute("CREATE INDEX idx_roteadores_ip ON roteadores_core(ip_gerencia);")

# DQL: Consulta preservada sem alterações
cursor.execute("SELECT hostname, ip_gerencia, fabricante, capacidade_gbps FROM roteadores_core;")
for row in cursor.fetchall():
    print(row)

In [4]: TCL: Transações, Pontos de Salvamento (Savepoints) e Rollback 
# Estabelecendo marco transacional
cursor.execute("SAVEPOINT sp_seguro;")

# Atualização temporária indevida
cursor.execute("UPDATE roteadores_core SET capacidade_gbps = 999 WHERE hostname = 'TAU-CORE-01';")

# Reversão via TCL
cursor.execute("ROLLBACK TO sp_seguro;")
print("✅ [TCL] Operação revertida via ROLLBACK TO SAVEPOINT!")

# Teste com violação de CHECK constraint (capacidade_gbps > 0)
try:
    cursor.execute("UPDATE roteadores_core SET capacidade_gbps = -10 WHERE hostname = 'TAU-CORE-01';")
except sqlite3.IntegrityError as err:
    print(f"⚠️  [CHECK Constraint] O SGBD impediu a inconsistência: {err}")
    cursor.execute("ROLLBACK TO sp_seguro;")

cursor.execute("RELEASE SAVEPOINT sp_seguro;")
conn.commit()
print("✅ [TCL] Transação finalizada com integridade total.")
Out [4]:

✅ [TCL] Transação finalizada com integridade total.
