1. O Que É um Sistema de Banco de Dados?

Em aplicações de Telemática e Redes de Comunicação, dados de dispositivos, configurações de rotas, telemetria e registros de tráfego precisam ser persistidos de forma segura, concorrente e confiável. O Sistema Gerenciador de Banco de Dados (SGBD) provê:

  • Independência de Dados: Separação entre a estrutura física no disco e a visão lógica da aplicação.
  • Integridade Referencial: Regras estritas garantindo que links entre dispositivos e interfaces não fiquem órfãos.
  • Linguagem Declarativa Padronizada (SQL): Consultas expressivas e otimizadas pelo motor do banco.
In [1]: Criação de Tabelas Relacionais com SQLite 
import sqlite3

# Conexão com banco em memória
conn = sqlite3.connect(":memory:")
cursor = conn.cursor()

# DDL: Criando tabelas de dispositivos de rede e interfaces
cursor.execute("""
CREATE TABLE dispositivos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hostname TEXT NOT NULL UNIQUE,
    tipo TEXT NOT NULL,
    localizacao TEXT NOT NULL
);
""")

cursor.execute("""
CREATE TABLE interfaces (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    dispositivo_id INTEGER NOT NULL,
    nome_interface TEXT NOT NULL,
    ip_address TEXT NOT NULL,
    mac_address TEXT NOT NULL UNIQUE,
    FOREIGN KEY (dispositivo_id) REFERENCES dispositivos(id)
);
""")

print("✅ Tabelas relacionais criadas com sucesso!")

In [2]: Inserção de Dados e Consulta Relacional com JOIN 
# Inserindo um switch e suas interfaces
cursor.execute("INSERT INTO dispositivos (hostname, tipo, localizacao) VALUES (?, ?, ?)",
               ("SW-CORE-01", "Switch L3", "Rack 01 - Sala de Servidores"))
disp_id = cursor.lastrowid

interfaces = [
    (disp_id, "GigabitEthernet0/1", "192.168.1.1", "00:1A:2B:3C:4D:5E"),
    (disp_id, "GigabitEthernet0/2", "10.0.0.1", "00:1A:2B:3C:4D:5F")
]
cursor.executemany("INSERT INTO interfaces (dispositivo_id, nome_interface, ip_address, mac_address) VALUES (?, ?, ?, ?)", interfaces)
conn.commit()

# Consulta com JOIN
query = """
SELECT d.hostname, d.tipo, i.nome_interface, i.ip_address, i.mac_address
FROM dispositivos d
JOIN interfaces i ON i.dispositivo_id = d.id
"""

for row in cursor.execute(query).fetchall():
    print(row)
